# 图片背景移除（透明背景 PNG）

用 `remove_background` 把图片主体抠出来，输出带 alpha 通道的 PNG。推理完全在本机完成，图片不会上传到任何服务。

## 何时使用

- 用户说“抠图”“去背景”“把背景去掉”“做成透明 PNG”“批量处理这批图片”。
- 需要把商品图、人像、Logo 放到其他背景上时。
- 不需要使用：用户只是要裁剪、压缩、转换格式，或要求保留背景。

## 参数

| 参数 | 说明 |
| --- | --- |
| `input` | 必填。图片文件路径，或包含图片的目录。相对路径按当前工作目录解析。 |
| `output` | 可选。单图可为 `.png` 文件或目录；批量时必须为目录。省略时写到原图同目录的 `<原名>-cutout.png`；批量省略时写到同级 `<目录名>-cutout/`。 |
| `model` | `fast`（默认，u2netp，日常照片更快）或 `quality`（ISNet，发丝与复杂边缘更好但更慢）。两个模型都随插件打包，无需下载。 |
| `overwrite` | 默认 `false`。任一输出已存在时整批报错且不处理，确认覆盖再传 `true`。 |

## 使用规则

1. 单张图片直接调用一次；目录批量传 `input` 目录并指定 `output` 目录，**不要逐张循环调用**。
2. 不要把同一张图重复调用多次；工具返回的 `items` 已包含输出路径、尺寸和前景占比。
3. 用户没有指定输出位置时省略 `output`，不要自行编造路径。
4. 返回结果里有输出文件路径，向用户汇报路径和数量即可，不要粘贴 base64 或大段 JSON。
5. 工具报“模型缺失”时，说明插件安装不完整需要重装，或建议改用 `fast`，不要尝试联网调用其他抠图服务。

## 注意事项

- 支持 PNG、JPEG、WebP、TIFF、BMP、AVIF；GIF 只取第一帧。
- 输入会按 EXIF 方向自动旋转，输出尺寸与旋转后的原图一致。
- 失败时工具直接抛错（路径不存在、格式不支持、输出已存在、模型缺失），按错误提示修正参数后重试一次。
