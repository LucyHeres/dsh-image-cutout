# 图片背景移除器

一键移除图片背景——可批量上传商品图、人像、复杂场景。

它可以把你照片里的主体抠出来，保存成背景透明或纯色的 PNG。图片只在你自己的电脑上处理，不会上传到网上。

## 快速上手

选择图片 → 开始抠图 → 选择背景颜色 → 下载全部

## 打开插件

1. 打开薪灵。
2. 在左侧边栏点击「图片背景移除器」。
3. 如果没有看到入口，请确认插件已经启用，然后按 ⌘Q 完全退出薪灵，再重新打开。

## 三步完成抠图

### 1. 选择图片

点击虚线框中间的大加号，可以一次选择一张或多张图片。

已经选好的图片会横向排列。点缩略图右上角的 × 可以移除某一张。

### 2. 选择模型

- **快速**：日常照片、商品图，出图更快，推荐先用这个。
- **高清**：发丝、毛发和复杂边缘更细致，等待时间会更长。

不确定选哪个时，保持默认的「快速」即可。

### 3. 开始抠图

点击「开始抠图」。

处理过程中可以随时点「停止」，已经完成的图片会保留。选图和移除按钮会暂时不可用，处理结束后恢复。

某张图片失败时，其它图片不受影响，可以在失败的卡片上点「重试」。

## 选择背景颜色

处理完成后，在「结果」上方选择背景：

- 透明（默认）
- 红
- 蓝
- 黑
- 白

所有图片会同时应用这个颜色。切换颜色只会改变预览，**不会马上保存文件**，可以放心来回比较效果。

每张卡片右下角的「查看大图」可以查看细节。按 Esc，或点击弹窗外面的空白处即可关闭。

## 下载图片

确认背景颜色后：

1. 点击「下载全部」。
2. 在系统弹出的窗口里选择保存位置（默认打开「下载」文件夹）。
3. 点「选择」后，所有处理成功的图片会一起保存到你选好的文件夹。

如果取消了选择窗口，不会保存任何图片。

## 保存的文件

- 文件格式：PNG。
- 文件名：原文件名加 `-cutout`。例如 `portrait.jpg` 会保存为 `portrait-cutout.png`。
- 如果目标文件夹里已有同名文件，不会覆盖原文件，会自动改用 `portrait-cutout-2.png`、`portrait-cutout-3.png`。
- 只有点了「下载全部」并选好文件夹，才会写入图片。单纯切换颜色不会在原图旁边生成文件。

## 支持的图片

支持 PNG、JPEG、WebP、TIFF、BMP、AVIF。

GIF 只处理第一帧，并保存为 PNG。建议使用主体清晰、边缘完整的照片，效果更好。

## 图片安全

- 抠图和保存都在你的电脑上完成。
- 不会把图片上传到任何服务器，也不需要登录。
- 只有你主动点「下载全部」时，结果才会写到你自己选择的文件夹。

## 在对话里使用

也可以直接在对话里对助手说：

> 帮我把这张照片的背景去掉

> 把这几个商品图的背景去掉，保存到桌面

助手会把结果显示在聊天里，并按你的要求把图片保存到你指定的位置。

## 常见问题

**看不到侧边栏入口？**
确认插件已启用。升级插件后，需要按 ⌘Q 完全退出薪灵再打开；只关闭窗口或刷新页面不够。

**提示「抠图宿主接口尚未加载」或出现 404？**
同样需要完全退出薪灵再重新打开，让新版本生效。

**点了「下载全部」没有反应？**
系统选择窗口可能在等待你选择文件夹，也可能被其他窗口挡住了。取消选择不会保存任何文件。

**某张图片失败了？**
常见原因是格式不支持、文件损坏或图片太小。可以先换成 PNG 或 JPEG，再点「重试」。

**换了颜色，但保存出来的图片没变？**
选颜色只改变预览。要保存当前颜色，需要再点一次「下载全部」，并重新选择保存位置。

**发丝边缘不够干净？**
试试「高清」模型，处理时间会更长一些。

**可以用 Windows 吗？**
页面的「选择图片」和「选择保存文件夹」按钮目前仅支持 macOS。

## 进阶设置

插件设置里可以调整默认模型、模型文件夹和单次批量上限。一般保持默认即可，不影响日常使用。
